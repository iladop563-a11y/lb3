# Лабораторна робота №3 — Python

**Тема:** Обробка винятків, модулі, пакети, документація та інтроспекція.  
**Виконав:** Ілля Кузін.

## Завдання

1. Обробка винятків: `try/except`, `else`, `finally`, кілька типів помилок.
2. Власні винятки магазину та журналювання помилок.
3. Організація коду в пакет `shop`, імпорт функцій та `__all__`.
4. Документація функції `create_product`, `__name__`, `__doc__`, `__annotations__`, `help()`.

## Вимоги

- Python 3.10 або новіший (у звіті використано Python 3.14).
- Сторонні бібліотеки не потрібні.

## Запуск

1. Завантажте репозиторій через **Code → Download ZIP** та розпакуйте його або клонуйте командою `git clone <адреса-репозиторію>`.
2. Відкрийте термінал у папці проєкту (де лежить `lb3.py`).
3. Запустіть:

   ```bash
   python lb3.py
   ```

   Альтернативний запуск:

   ```bash
   python -m shop
   ```

Програма послідовно виводить результати чотирьох завдань. Файл `shop.log` створюється автоматично під час запуску і не додається до Git.
